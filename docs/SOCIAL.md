## LinkedIn

Building **ShipFlow AI** for the ChaiCode "Feature to Production" hackathon 🚀

Great software isn't shipped by code generation alone — every feature follows a process. ShipFlow is a full-stack, multi-tenant SaaS that runs that whole process:

Request → Product thinking → PRD → Tasks → Code → AI Review → Fixes → Re-Review → Human Approval → Ship

What makes it more than a wrapper:
• An AI **QA + engineering reviewer** that judges a pull request against the PRD and its acceptance criteria — not just syntax — and explains *why* each issue matters
• Real GitHub App integration (webhooks, PR diffs, review comments — no hardcoded data)
• Async AI workflows with live in-app progress
• A human approval gate — the AI advises, a human decides

Stack: Next.js · tRPC monorepo · Prisma/Postgres · BetterAuth · Octokit · AI SDK · Inngest · Razorpay · Vercel.
